# Action Recorder & Player - Chrome Extension

Extension Chrome puissante pour enregistrer et rejouer des interactions sur le web.

## Installation

1. Ouvrez Chrome et allez sur `chrome://extensions/`.
2. Activez le **Mode développeur** en haut à droite.
3. Cliquez sur **Charger l'extension non empaquetée**.
4. Sélectionnez le dossier `plugin-mkp`.

## Utilisation

1. Cliquez sur l'icône de l'extension.
2. Cliquez sur **Enregistrer** (⏺️).
3. Naviguez sur la page, remplissez des formulaires, cliquez, etc.
4. Ouvrez à nouveau l'extension et cliquez sur **Arrêter** (⏹️).
5. Donnez un nom à votre scénario et sauvegardez.
6. Pour rejouer, cliquez sur le bouton **Play** (▶️) à côté du scénario.

## Fonctionnalités Clés
- Enregistrement fidèle des délais.
- Sélecteurs XPath robustes.
- Lecteur avec mise en évidence visuelle.
- Export et Import en JSON.
